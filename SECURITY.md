# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use the private report of this repository instead: **Security** tab, then **Report a vulnerability** (or <https://github.com/privadosIA/dashboards-labs/security/advisories/new>).

Say what is affected, how to repeat it and, if you can, what you think the impact is. The repository is maintained by one person in their free time, so there is no promised response time; a report is read as soon as possible.

## Supported version

Only the last commit of `main`.
